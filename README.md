# Network Adaptor Auto Reset (PowerShell)

مانیتور و بازیاب خودکار اتصال اینترنت برای ویندوز

## قابلیت‌ها

- بررسی اتصال اینترنت هر 1 دقیقه (تست HTTP رسمی مایکروسافت + Ping به چند سرور)
- در صورت قطعی اینترنت، ری‌استارت خودکار آداپتورهای شبکه (Disable سپس Enable)
- ثبت خودکار در استارتآپ ویندوز در اولین اجرا (Scheduled Task + Registry Run)
- اجرای خودکار با دسترسی Administrator
- لاگ‌گیری کامل با چرخش خودکار فایل

## سازگاری

Windows 8 / 8.1 / 10 / 11 و Windows Server 2012+

## استفاده

1. فایل‌های پوشه `v1.0-powershell` را در یک پوشه کپی کنید
2. روی `Install.bat` کلیک راست و **Run as administrator**
3. در اولین اجرا، برنامه خود را در استارتآپ ثبت می‌کند
