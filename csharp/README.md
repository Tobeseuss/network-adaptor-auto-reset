# Network Watchdog - نگهبان شبکه

مانیتور و بازیاب خودکار اتصال اینترنت **با محافظت شبکه محلی دوربین‌ها**

سازگار با: **Windows 7 SP1 / 8 / 8.1 / 10 / 11**

---

## قابلیت‌ها

- بررسی دوره‌ای اتصال اینترنت (پیش‌فرض هر 1 دقیقه) با روش‌های Ping + TCP (دو‌لایه و مقاوم)
- **محافظت شبکه دوربین‌ها**: اگر IP شبکه محلی (پیش‌فرض `192.168.1.1` - قابل تغییر) در دسترس باشد، حتی وقتی اینترنت قطع است شبکه ری‌استارت **نمی‌شود** تا تصاویر دوربین‌ها قطع نشود
- در صورت قطع کامل شبکه (اینترنت + شبکه محلی)، آداپتورهای شبکه به‌صورت خودکار Disable و سپس Enable می‌شوند
- **موتور ری‌استارت سه‌لایه (v2.2)**: `netsh` (اصلی - منطق اسکریپت پایتون RestartNetworkAdaptors) ← `WMI` (جایگزین) ← `PowerShell Restart-NetAdapter` (آخرین) + **تایید وضعیت واقعی آداپتور** پس از هر ری‌استارت
- **پنجره لاگ زنده (v2.2)**: دیدن لحظه‌ای اینکه دقیقاً چه کاری انجام شده، چه کاری در حال انجام است و چه دستوراتی اجرا می‌شود - با رنگ‌بندی سطح پیام، فیلتر، توقف نمایش، کپی و ذخیره (کلیک راست روی آیکون ← پنجره لاگ زنده یا دابل‌کلیک روی آیکون)
- آیکون کنار ساعت (System Tray) با رنگ وضعیت:
  - **سبز**: اینترنت و شبکه محلی هر دو سالم
  - **نارنجی**: یکی از دو اتصال قطع است (مثلاً فقط اینترنت قطع ولی دوربین‌ها وصل‌اند)
  - **قرمز**: قطع کامل شبکه
- پنجره تنظیمات فارسی (کلیک راست روی آیکون ← تنظیمات)
- ثبت خودکار در استارتآپ ویندوز در اولین اجرا (Scheduled Task با دسترسی کامل - بدون پنجره UAC در بوت‌های بعدی)
- لاگ کامل از تمام رویدادها و **دستورات اجراشده با کد خروج** با چرخش خودکار فایل
- خروجی EXE - کامپایل با کامپایلر داخلی خود ویندوز، **بدون نیاز به نصب هیچ نرم‌افزاری**

## منطق تصمیم‌گیری برنامه

```
هر 60 ثانیه (قابل تغییر):
├── اینترنت وصل است؟
│   ├── بله → اگر شبکه محلی هم وصل است: سبز و ادامه
│   │        اگر شبکه محلی قطع است: نارنجی + هشدار لاگ (ری‌استارت نمی‌کند تا اینترنت خراب نشود)
│   └── خیر ↓
├── شبکه محلی (192.168.1.1) وصل است؟
│   ├── بله (محافظت فعال) → نارنجی؛ ری‌استارت انجام نمی‌شود (حفظ تصاویر دوربین)
│   └── خیر (قطع کامل) → قرمز؛ ری‌استارت آداپتورها + بررسی مجدد
```

## ساخت خروجی EXE (کامپایل)

فایل‌های زیر باید در یک پوشه باشند:

```
NetworkWatchdogApp\
├── NetworkWatchdog.cs    ← سورس کامل برنامه
├── app.manifest          ← مانیفست (درخواست دسترسی Administrator + سازگاری Win7 تا Win11)
├── app.ico               ← آیکون برنامه
├── build.bat             ← اسکریپت ساخت
└── Uninstall.bat         ← حذف کامل مستقل (اگر برنامه در حال اجرا نیست)
```

1. روی ویندوز (7/10/11) به پوشه بروید
2. روی **build.bat** دوبار کلیک کنید
3. فایل **NetworkWatchdog.exe** ساخته می‌شود

> کامپایلر csc.exe داخل تمام ویندوزها از قبل نصب است؛ هیچ نیاز به Visual Studio یا SDK ندارید.

## اجرا و نصب

1. روی **NetworkWatchdog.exe** کلیک راست ← **Run as administrator** (یا دابل‌کلیک؛ خودش UAC می‌خواهد)
2. در اولین اجرا، برنامه:
   - خود را در استارتآپ ویندوز ثبت می‌کند (Scheduled Task با نام `NetworkWatchdog`)
   - فایل تنظیمات پیش‌فرض می‌سازد
   - آیکون سبز کنار ساعت ظاهر می‌شود
3. از این پس هر بار ویندوز بالا بیاید، برنامه خودکار و **بدون پنجره UAC** اجرا می‌شود

## تنظیمات

کلیک راست روی آیکون ← **تنظیمات...**

| تنظیم | پیش‌فرض | توضیح |
|---|---|---|
| آدرس‌های بررسی اینترنت | `8.8.8.8, 1.1.1.1, 208.67.222.222` | سرورهای تست اینترنت |
| **آدرس‌های شبکه محلی / دوربین‌ها** | `192.168.1.1` | **IP مودم/سوئیچ شبکه دوربین‌ها - روتر یا هر IP همیشه روشن شبکه محلی** |
| محافظت شبکه محلی | فعال | اگر این IP وصل باشد، هرگز ری‌استارت نکن |
| فاصله هر بررسی | 60 ثانیه | دوره بررسی |
| مهلت هر تست | 2000ms | Timeout هر Ping/TCP |
| تاخیر غیرفعال/فعال | 5 ثانیه | فاصله بین Disable و Enable |
| صبر بالا آمدن آداپتور | 10 ثانیه | بعد از Enable چقدر صبر کند |
| تعداد تلاش مجدد | 3 | برای هر آداپتور |
| الگوی حذف آداپتور مجازی | Regex پیش‌فرض | آداپتورهای VPN/VMware/Hyper-V حذف می‌شوند |

فایل تنظیمات: `%APPDATA%\NetworkWatchdog\settings.xml`

## منوی کلیک راست آیکون

- **وضعیت**: وضعیت لحظه‌ای اینترنت و دوربین‌ها
- **بررسی هم‌اکنون**: تست فوری بدون انتظار برای سیکل بعدی
- **ری‌استارت شبکه (دستی)**: با تایید، آداپتورها را ری‌استارت می‌کند (پنجره لاگ زنده خودکار باز می‌شود تا مراحل را ببینید)
- **تنظیمات...**: پنجره تنظیمات فارسی
- **پنجره لاگ زنده**: دیدن لحظه‌ای فعالیت‌ها، نتایج و دستورات در حال اجرا (دابل‌کلیک روی آیکون هم همین پنجره را باز می‌کند)
- **مشاهده فایل لاگ**: باز کردن لاگ در Notepad
- **اجرای خودکار هنگام روشن شدن ویندوز**: فعال/غیرفعال کردن استارتآپ
- **حذف کامل برنامه (Uninstall)**: حذف کامل با چند کلیک (پایین را ببینید)

## پنجره لاگ زنده

برای دیدن اینکه برنامه دقیقاً چه می‌کند: کلیک راست روی آیکون ← **پنجره لاگ زنده** (یا دابل‌کلیک روی آیکون).

- هر خط لاگ (اجرا/خروجی/کد خروج دستورات، نتیجه Ping هر سرور، مراحل ری‌استارت و ...) لحظه‌ای و با **رنگ‌بندی** نمایش داده می‌شود (خطا=قرمز، هشدار=کهربایی، ریزه‌کاری=خاکستری)
- **نوار وضعیت پایین** نشان می‌دهد الان چه کاری در حال انجام است (مثلاً «ری‌استارت آداپتور 1 از 2: «Ethernet»»)
- تاریخچه قبلی (انتهای فایل لاگ) هم هنگام باز شدن بارگذاری می‌شود
- امکانات: فیلتر سطح پیام، اسکرول خودکار، توقف/ادامه نمایش، کپی همه، ذخیره در فایل، پاک کردن نمایش

## حذف برنامه (Uninstall)

### روش 1 - از داخل خود برنامه (پیشنهادی)

1. کلیک راست روی آیکون ← **حذف کامل برنامه (Uninstall)**
2. به سوال‌ها پاسخ دهید:
   - سوال اول: تایید شروع حذف
   - سوال دوم: حذف یا نگه‌داشتن فایل‌های تنظیمات و لاگ
3. برنامه به‌صورت خودکار: استارتآپ را پاک می‌کند، آثار نسخه قبلی PowerShell را حذف می‌کند، بسته می‌شود و فایل EXE (و در صورت انتخاب، پوشه‌های داده) را در پس‌زمینه حذف می‌کند

### روش 2 - اسکریپت مستقل (وقتی برنامه در حال اجرا نیست)

1. فایل **Uninstall.bat** (کنار همین فایل‌ها) را **Run as administrator** کنید
2. تایید `y` را بزنید — تمام موارد (تسک استارتآپ، رجیستری، پوشه‌های داده و فایل EXE) پاک می‌شوند

### روش 3 - دستی (در صورت نیاز)

1. کلیک راست روی آیکون ← **خروج**
2. از منوی Start برنامه **Task Scheduler** را باز کنید (یا `taskschd.msc` در Run)
3. از پوشه Task Scheduler Library تسک **NetworkWatchdog** را حذف کنید
4. پوشه‌های `%APPDATA%\NetworkWatchdog` و `%LOCALAPPDATA%\NetworkWatchdog` را حذف کنید
5. فایل EXE را پاک کنید

## نکات فنی

- **موتور ری‌استارت (v2.2 - منطق اسکریپت پایتون RestartNetworkAdaptors)**: روش اصلی `netsh interface set interface ... admin=disable/enable` است؛ اگر موفق نبود به‌ترتیب `WMI` (Win32_NetworkAdapter) و سپس `powershell Restart-NetAdapter` (ویندوز 8+) امتحان می‌شوند. پس از هر ری‌استارت، وضعیت واقعی آداپتور از طریق WMI تایید می‌شود و نتیجه در لاگ ثبت می‌گردد.
- کشف آداپتورها از **دو منبع** انجام می‌شود: WMI (همه آداپتورهای دارای نام اتصال - فعال و غیرفعال) + خروجی `netsh interface show interface`؛ اگر آداپتوری در ری‌استارت قبلی غیرفعال مانده باشد، در چرخه بعدی **دوباره فعال** می‌شود (خودترمیم)
- آداپتورهای مجازی (VPN/VMware/Hyper-V/TAP/...) با الگوی Regex قابل تنظیم حذف می‌شوند
- تست اینترنت دو مرحله‌ای است: اول Ping به سرورهای DNS عمومی؛ اگر ICMP فیلتر شده باشد، اتصال TCP به پورت 53 تست می‌شود
- اگر اینترنت وصل باشد ولی شبکه محلی قطع باشد، ری‌استارت خودکار انجام **نمی‌شود** (تا اینترنت سالم نشکند) و فقط هشدار در لاگ و آیکون نارنجی نمایش داده می‌شود
- اجرای همزمان دو نسخه از برنامه با Mutex جلوگیری می‌شود
- زبان کد C# 4.0 / .NET Framework 4 است تا با کامپایلر داخلی ویندوز 7 هم کامپایل شود

## عیب‌یابی

| مشکل | راه حل |
|---|---|
| `csc.exe not found` هنگام Build | .NET Framework 4.x را از لینک بالا نصب کنید و دوباره build.bat را اجرا کنید |
