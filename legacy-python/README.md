# اسکریپت پایتون مرجع (Legacy)

این اسکریپت (`RestartNetworkAdaptors.py`) نسخه اولیهٔ شخصیِ کاربر برای ری‌استارت آداپتورهای شبکه است که منطق آن **اثبات‌شده** بود و جواب می‌داد.

در نسخه **v2.2.0** برنامه C# (`../csharp/`) دقیقاً همین منطق با C#/.NET پیاده‌سازی و ادغام شد:

- کشف آداپتورها از چند منبع (WMI + `netsh interface show interface`)
- ری‌استارت با **netsh به‌عنوان روش اصلی** (`admin=disable` → تاخیر → `admin=enable`)
- تایید وضعیت پس از ری‌استارت (کلیدواژه Connected/Enabled در خروجی netsh + WMI)
- روش جایگزین PowerShell `Restart-NetAdapter`

این فایل صرفاً جهت مرجع و مستندسازی نگهداری می‌شود و برای اجرای روزمره لازم نیست.
